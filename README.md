# ТОО «Джамиля» — Ежедневный отчёт по продажам

Адаптивный статический dashboard для ежедневного отчёта руководителю.

## Что есть

- Продажи / общая сумма реализации
- Динамика продаж по цехам
- Детализация по цехам:
  - Кресельный цех
  - Корпусный цех
  - Покрасочный цех
  - Стульный цех
  - Швейный цех
  - Сервисный центр ТОО «Джамиля»
  - Склад готовой продукции (для отгрузки) Джамиля
- Ручной ввод суммы каждого цеха
- Автоматический пересчёт общей реализации
- Кнопка «Скачать PDF» через печать браузера
- Адаптивная версия для компьютера и планшета
- Имя руководителя: Нурсултан
- Валюта: ₸

## Запуск локально

Откройте `index.html` в браузере.

## Развёртывание на GitHub Pages

1. Создайте новый GitHub repository.
2. Загрузите `index.html` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`.
6. Сохраните настройки.

Через некоторое время GitHub Pages выдаст публичную ссылку на сайт.

## PDF

Нажмите **«Скачать PDF»** → в диалоге печати выберите **«Сохранить как PDF»**.
